# Living Manuscript artwork

Created 28 October 2026 with the built-in image generation tool, using the owner's supplied Living Manuscript concept as the visual reference. The owner explicitly requested implementation and production publication of that design.

- hero-1600.webp / hero-800.webp: original generated open illuminated manuscript, blank right page; all displayed title and prose are real HTML from existing source-linked stories.
- journey-1600.webp: original generated thematic landscape. It is explicitly presented as a thematic journey, not a geographic map.
- manuscript-mark.svg: vector sunrise treatment matching the supplied reference and existing sunrise identity.

These decorative illustrations do not establish historical accuracy, editorial review, or scriptural provenance. Existing story text and source links are unchanged. Generated source PNGs remain in the local generated_images directory; optimized assets are committed with the site.
