Shloka

कुन्देन्दीवरसुन्दरावतिबलौ विज्ञानधामावुभौkundendīvarasundarāvatibalau vijñānadhāmāvubhau

शोभाढ्यौ वरधन्विनौ श्रुतिनुतौ गोविप्रवृन्दप्रियौ।śobhāḍhyau varadhanvinau śrutinutau govipravr̥ndapriyau /

मायामानुषरूपिणौ रघुवरौ सद्धर्मवर्मौं हितौmāyāmānuṣarūpiṇau raghuvarau saddharmavarmauṃ hitau

सीतान्वेषणतत्परौ पथिगतौ भक्तिप्रदौ तौ हि नः।।1।।sītānveṣaṇatatparau pathigatau bhaktipradau tau hi naḥ //

Shloka

ब्रह्माम्भोधिसमुद्भवं कलिमलप्रध्वंसनं चाव्ययंbrahmāmbhodhisamudbhavaṃ kalimalapradhvaṃsanaṃ cāvyayaṃ

श्रीमच्छम्भुमुखेन्दुसुन्दरवरे संशोभितं सर्वदा।śrīmacchambhumukhendusundaravare saṃśobhitaṃ sarvadā /

संसारामयभेषजं सुखकरं श्रीजानकीजीवनंsaṃsārāmayabheṣajaṃ sukhakaraṃ śrījānakījīvanaṃ

धन्यास्ते कृतिनः पिबन्ति सततं श्रीरामनामामृतम्।।2।।dhanyāste kr̥tinaḥ pibanti satataṃ śrīrāmanāmāmr̥tam //

Soratha

मुक्ति जन्म महि जानि ग्यान खानि अघ हानि कर।mukti janma mahi jāni gyāna khāni agha hāni kara /

जहँ बस संभु भवानि सो कासी सेइअ कस न।।jahã basa saṃbhu bhavāni so kāsī seia kasa na //

Soratha

जरत सकल सुर बृंद बिषम गरल जेहिं पान किय।jarata sakala sura br̥ṃda biṣama garala jehiṃ pāna kiya /

तेहि न भजसि मन मंद को कृपाल संकर सरिस।।tehi na bhajasi mana maṃda ko kr̥pāla saṃkara sarisa //

Dohas 1–10

आगें चले बहुरि रघुराया। रिष्यमूक परवत निअराया।।āgeṃ cale bahuri raghurāyā / riṣyamūka paravata niarāyā //

तहँ रह सचिव सहित सुग्रीवा। आवत देखि अतुल बल सींवा।।tahã raha saciva sahita sugrīvā / āvata dekhi atula bala sīṃvā //

अति सभीत कह सुनु हनुमाना। पुरुष जुगल बल रूप निधाना।।ati sabhīta kaha sunu hanumānā / puruṣa jugala bala rūpa nidhānā //

धरि बटु रूप देखु तैं जाई। कहेसु जानि जियँ सयन बुझाई।।dhari baṭu rūpa dekhu taiṃ jāī / kahesu jāni jiyã sayana bujhāī //

पठए बालि होहिं मन मैला। भागौं तुरत तजौं यह सैला।।paṭhae bāli hohiṃ mana mailā / bhāgauṃ turata tajauṃ yaha sailā //

बिप्र रूप धरि कपि तहँ गयऊ। माथ नाइ पूछत अस भयऊ।।bipra rūpa dhari kapi tahã gayaū / mātha nāi pūchata asa bhayaū //

को तुम्ह स्यामल गौर सरीरा। छत्री रूप फिरहु बन बीरा।।ko tumha syāmala gaura sarīrā / chatrī rūpa phirahu bana bīrā //

कठिन भूमि कोमल पद गामी। कवन हेतु बिचरहु बन स्वामी।।kaṭhina bhūmi komala pada gāmī / kavana hetu bicarahu bana svāmī //

मृदुल मनोहर सुंदर गाता। सहत दुसह बन आतप बाता।।mr̥dula manohara suṃdara gātā / sahata dusaha bana ātapa bātā //

की तुम्ह तीनि देव महँ कोऊ। नर नारायन की तुम्ह दोऊ।।kī tumha tīni deva mahã koū / nara nārāyana kī tumha doū //

Doha

जग कारन तारन भव भंजन धरनी भार।jaga kārana tārana bhava bhaṃjana dharanī bhāra /

की तुम्ह अकिल भुवन पति लीन्ह मनुज अवतार।।1।।kī tumha akila bhuvana pati līnha manuja avatāra //

कोसलेस दसरथ के जाए। हम पितु बचन मानि बन आए।।kosalesa dasaratha ke jāe / hama pitu bacana māni bana āe //

नाम राम लछिमन दोउ भाई। संग नारि सुकुमारि सुहाई।।nāma rāma lachimana dou bhāī / saṃga nāri sukumāri suhāī //

इहाँ हरि निसिचर बैदेही। बिप्र फिरहिं हम खोजत तेही।।ihā̃ hari nisicara baidehī / bipra phirahiṃ hama khojata tehī //

आपन चरित कहा हम गाई। कहहु बिप्र निज कथा बुझाई।।āpana carita kahā hama gāī / kahahu bipra nija kathā bujhāī //

प्रभु पहिचानि परेउ गहि चरना। सो सुख उमा नहिं बरना।।prabhu pahicāni pareu gahi caranā / so sukha umā nahiṃ baranā //

पुलकित तन मुख आव न बचना। देखत रुचिर बेष कै रचना।।pulakita tana mukha āva na bacanā / dekhata rucira beṣa kai racanā //

पुनि धीरजु धरि अस्तुति कीन्ही। हरष हृदयँ निज नाथहि चीन्ही।।puni dhīraju dhari astuti kīnhī / haraṣa hr̥dayã nija nāthahi cīnhī //

मोर न्याउ मैं पूछा साईं। तुम्ह पूछहु कस नर की नाईं।।mora nyāu maiṃ pūchā sāīṃ / tumha pūchahu kasa nara kī nāīṃ //

तव माया बस फिरउँ भुलाना। ता ते मैं नहिं प्रभु पहिचाना।।tava māyā basa phiraũ bhulānā / tā te maiṃ nahiṃ prabhu pahicānā //

Doha

एकु मैं मंद मोहबस कुटिल हृदय अग्यान।eku maiṃ maṃda mohabasa kuṭila hr̥daya agyāna /

पुनि प्रभु मोहि बिसारेउ दीनबंधु भगवान।।2।।puni prabhu mohi bisāreu dīnabaṃdhu bhagavāna //

जदपि नाथ बहु अवगुन मोरें। सेवक प्रभुहि परै जनि भोरें।।jadapi nātha bahu avaguna moreṃ / sevaka prabhuhi parai jani bhoreṃ //

नाथ जीव तव मायाँ मोहा। सो निस्तरइ तुम्हारेहिं छोहा।।nātha jīva tava māyā̃ mohā / so nistarai tumhārehiṃ chohā //

ता पर मैं रघुबीर दोहाई। जानउँ नहिं कछु भजन उपाई।।tā para maiṃ raghubīra dohāī / jānaũ nahiṃ kachu bhajana upāī //

सेवक सुत पति मातु भरोसें। रहइ असोच बनइ प्रभु पोसें।।sevaka suta pati mātu bharoseṃ / rahai asoca banai prabhu poseṃ //

अस कहि परेउ चरन अकुलाई। निज तनु प्रगटि प्रीति उर छाई।।asa kahi pareu carana akulāī / nija tanu pragaṭi prīti ura chāī //

तब रघुपति उठाइ उर लावा। निज लोचन जल सींचि जुड़ावा।।taba raghupati uṭhāi ura lāvā / nija locana jala sīṃci juṛāvā //

सुनु कपि जियँ मानसि जनि ऊना। तैं मम प्रिय लछिमन ते दूना।।sunu kapi jiyã mānasi jani ūnā / taiṃ mama priya lachimana te dūnā //

समदरसी मोहि कह सब कोऊ। सेवक प्रिय अनन्यगति सोऊ।।samadarasī mohi kaha saba koū / sevaka priya ananyagati soū //

Doha

सो अनन्य जाकें असि मति न टरइ हनुमंत।so ananya jākeṃ asi mati na ṭarai hanumaṃta /

मैं सेवक सचराचर रूप स्वामि भगवंत।।3।।maiṃ sevaka sacarācara rūpa svāmi bhagavaṃta //

देखि पवन सुत पति अनुकूला। हृदयँ हरष बीती सब सूला।।dekhi pavana suta pati anukūlā / hr̥dayã haraṣa bītī saba sūlā //

नाथ सैल पर कपिपति रहई। सो सुग्रीव दास तव अहई।।nātha saila para kapipati rahaī / so sugrīva dāsa tava ahaī //

तेहि सन नाथ मयत्री कीजे। दीन जानि तेहि अभय करीजे।।tehi sana nātha mayatrī kīje / dīna jāni tehi abhaya karīje //

सो सीता कर खोज कराइहि। जहँ तहँ मरकट कोटि पठाइहि।।so sītā kara khoja karāihi / jahã tahã marakaṭa koṭi paṭhāihi //

एहि बिधि सकल कथा समुझाई। लिए दुऔ जन पीठि चढ़ाई।।ehi bidhi sakala kathā samujhāī / lie duau jana pīṭhi caṛhāī //

जब सुग्रीवँ राम कहुँ देखा। अतिसय जन्म धन्य करि लेखा।।jaba sugrīvã rāma kahũ dekhā / atisaya janma dhanya kari lekhā //

सादर मिलेउ नाइ पद माथा। भैंटेउ अनुज सहित रघुनाथा।।sādara mileu nāi pada māthā / bhaiṃṭeu anuja sahita raghunāthā //

कपि कर मन बिचार एहि रीती। करिहहिं बिधि मो सन ए प्रीती।।kapi kara mana bicāra ehi rītī / karihahiṃ bidhi mo sana e prītī //

Doha

तब हनुमंत उभय दिसि की सब कथा सुनाइ।taba hanumaṃta ubhaya disi kī saba kathā sunāi /

पावक साखी देइ करि जोरी प्रीती दृढ़ाइ।।4।।pāvaka sākhī dei kari jorī prītī dr̥ṛhāi //

कीन्ही प्रीति कछु बीच न राखा। लछमिन राम चरित सब भाषा।।kīnhī prīti kachu bīca na rākhā / lachamina rāma carita saba bhāṣā //

कह सुग्रीव नयन भरि बारी। मिलिहि नाथ मिथिलेसकुमारी।।kaha sugrīva nayana bhari bārī / milihi nātha mithilesakumārī //

मंत्रिन्ह सहित इहाँ एक बारा। बैठ रहेउँ मैं करत बिचारा।।maṃtrinha sahita ihā̃ eka bārā / baiṭha raheũ maiṃ karata bicārā //

गगन पंथ देखी मैं जाता। परबस परी बहुत बिलपाता।।gagana paṃtha dekhī maiṃ jātā / parabasa parī bahuta bilapātā //

राम राम हा राम पुकारी। हमहि देखि दीन्हेउ पट डारी।।rāma rāma hā rāma pukārī / hamahi dekhi dīnheu paṭa ḍārī //

मागा राम तुरत तेहिं दीन्हा। पट उर लाइ सोच अति कीन्हा।।māgā rāma turata tehiṃ dīnhā / paṭa ura lāi soca ati kīnhā //

कह सुग्रीव सुनहु रघुबीरा। तजहु सोच मन आनहु धीरा।।kaha sugrīva sunahu raghubīrā / tajahu soca mana ānahu dhīrā //

सब प्रकार करिहउँ सेवकाई। जेहि बिधि मिलिहि जानकी आई।।saba prakāra karihaũ sevakāī / jehi bidhi milihi jānakī āī //

Doha

सखा बचन सुनि हरषे कृपासिधु बलसींव।sakhā bacana suni haraṣe kr̥pāsidhu balasīṃva /

कारन कवन बसहु बन मोहि कहहु सुग्रीव।।5।।kārana kavana basahu bana mohi kahahu sugrīva //

नात बालि अरु मैं द्वौ भाई। प्रीति रही कछु बरनि न जाई।।nāta bāli aru maiṃ dvau bhāī / prīti rahī kachu barani na jāī //

मय सुत मायावी तेहि नाऊँ। आवा सो प्रभु हमरें गाऊँ।।maya suta māyāvī tehi nāū̃ / āvā so prabhu hamareṃ gāū̃ //

अर्ध राति पुर द्वार पुकारा। बाली रिपु बल सहै न पारा।।ardha rāti pura dvāra pukārā / bālī ripu bala sahai na pārā //

धावा बालि देखि सो भागा। मैं पुनि गयउँ बंधु सँग लागा।।dhāvā bāli dekhi so bhāgā / maiṃ puni gayaũ baṃdhu sãga lāgā //

गिरिबर गुहाँ पैठ सो जाई। तब बालीं मोहि कहा बुझाई।।giribara guhā̃ paiṭha so jāī / taba bālīṃ mohi kahā bujhāī //

परिखेसु मोहि एक पखवारा। नहिं आवौं तब जानेसु मारा।।parikhesu mohi eka pakhavārā / nahiṃ āvauṃ taba jānesu mārā //

मास दिवस तहँ रहेउँ खरारी। निसरी रुधिर धार तहँ भारी।।māsa divasa tahã raheũ kharārī / nisarī rudhira dhāra tahã bhārī //

बालि हतेसि मोहि मारिहि आई। सिला देइ तहँ चलेउँ पराई।।bāli hatesi mohi mārihi āī / silā dei tahã caleũ parāī //

मंत्रिन्ह पुर देखा बिनु साईं। दीन्हेउ मोहि राज बरिआई।।maṃtrinha pura dekhā binu sāīṃ / dīnheu mohi rāja bariāī //

बालि ताहि मारि गृह आवा। देखि मोहि जियँ भेद बढ़ावा।।bāli tāhi māri gr̥ha āvā / dekhi mohi jiyã bheda baṛhāvā //

रिपु सम मोहि मारेसि अति भारी। हरि लीन्हेसि सर्बसु अरु नारी।।ripu sama mohi māresi ati bhārī / hari līnhesi sarbasu aru nārī //

ताकें भय रघुबीर कृपाला। सकल भुवन मैं फिरेउँ बिहाला।।tākeṃ bhaya raghubīra kr̥pālā / sakala bhuvana maiṃ phireũ bihālā //

इहाँ साप बस आवत नाहीं। तदपि सभीत रहउँ मन माहीं।।ihā̃ sāpa basa āvata nāhīṃ / tadapi sabhīta rahaũ mana māhīṃ //

सुनि सेवक दुख दीनदयाला। फरकि उठीं द्वै भुजा बिसाला।।suni sevaka dukha dīnadayālā / pharaki uṭhīṃ dvai bhujā bisālā //

Doha

सुनु सुग्रीव मारिहउँ बालिहि एकहिं बान।sunu sugrīva mārihaũ bālihi ekahiṃ bāna /

ब्रम्ह रुद्र सरनागत गएँ न उबरिहिं प्रान।।6।।bramha rudra saranāgata gaẽ na ubarihiṃ prāna //

जे न मित्र दुख होहिं दुखारी। तिन्हहि बिलोकत पातक भारी।।je na mitra dukha hohiṃ dukhārī / tinhahi bilokata pātaka bhārī //

निज दुख गिरि सम रज करि जाना। मित्रक दुख रज मेरु समाना।।nija dukha giri sama raja kari jānā / mitraka dukha raja meru samānā //

जिन्ह कें असि मति सहज न आई। ते सठ कत हठि करत मिताई।।jinha keṃ asi mati sahaja na āī / te saṭha kata haṭhi karata mitāī //

कुपथ निवारि सुपंथ चलावा। गुन प्रगटे अवगुनन्हि दुरावा।।kupatha nivāri supaṃtha calāvā / guna pragaṭe avagunanhi durāvā //

देत लेत मन संक न धरई। बल अनुमान सदा हित करई।।deta leta mana saṃka na dharaī / bala anumāna sadā hita karaī //

बिपति काल कर सतगुन नेहा। श्रुति कह संत मित्र गुन एहा।।bipati kāla kara sataguna nehā / śruti kaha saṃta mitra guna ehā //

आगें कह मृदु बचन बनाई। पाछें अनहित मन कुटिलाई।।āgeṃ kaha mr̥du bacana banāī / pācheṃ anahita mana kuṭilāī //

About this text

The verses are the Ramcharitmanas of Goswami Tulsidas (16th century), in the original Awadhi. The text was compared word by word across three digital editions. Two of them (WirelessAlien and DharmicData) both name the IIT Kanpur Ramcharitmanas project as their source, so GRETIL is the only separate check. Where they disagreed, the reading two editions share was kept, and nothing was corrected from memory. The closing verses of the Ayodhya, Aranya and Lanka Kands are found in GRETIL alone, where the other two editions stop early. The text has not yet been checked against a printed edition.

  • WirelessAlien, Ramcharitmanas in JSON (Unlicense): the main text.
  • Bhavy Khatri, DharmicData, from the IIT Kanpur Ramcharitmanas project (ODbL 1.0): second edition, and the opening shlokas.
  • GRETIL, Göttingen, input by a group of volunteers at Ratlam: independent third edition, used to confirm the text and the only source for those closing verses.

The roman transliteration is generated from the Devanagari in the scholarly convention GRETIL uses. Episode titles and summaries are this site's own short retellings and are not part of the text. Paintings are illustrations made for this site.
