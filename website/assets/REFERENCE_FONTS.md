# Reference-faithful Latin typography

The illuminated-manuscript interface uses the same two Latin families observed in
the supplied reference while retaining the existing Devanagari fonts for Hindi.

- **Cormorant Garamond** — variable normal and italic Latin subsets, weights 300–700.
- **Manrope** — variable normal Latin subset, weights 200–800.

The files were resolved from the official Google Fonts CSS API on 6 October 2026
and downloaded from `fonts.gstatic.com`. Upstream source and license records are in
the Google Fonts repository:

- `google/fonts/ofl/cormorantgaramond`
- `google/fonts/ofl/manrope`

Both families are licensed under the SIL Open Font License 1.1. The exact license
texts are shipped beside the font assets as `OFL-Cormorant-Garamond.txt` and
`OFL-Manrope.txt`.
