## Build on this Mac

Run from `/Users/abhijay/Desktop/spritual/app`:

```sh
npm run mobile:doctor
npm run mobile:apk
```

`mobile:apk` builds the separate native bundle, syncs both platform projects, verifies packaged assets, compiles Android and writes `artifacts/Spritual-0.1.0-debug.apk`. It uses installed Java/Android SDK paths for its child processes only. No global shell changes, SDK installs or license acceptance are performed. The APK is a debug-signed test app, not a Play Store release.

Other commands:

```sh
npm run mobile:sync      # build, sync and verify both native projects
npm run mobile:verify    # compare current bundle against both synced copies
npm run mobile:assets    # regenerate icons and launch art from favicon.svg
npm run mobile:android   # open in Android Studio, if installed
npm run mobile:ios       # open the prepared Xcode project, if installed
```

The existing `npm run build` and `npm run preview` retain the web/PWA target. Native assets live in `web/dist-native`; web assets remain in `web/dist`. Generated assets, build output, local SDK settings, APKs and signing credentials are excluded from Git.

## Implemented mobile behaviour

- Android application ID and iOS bundle ID: `in.co.spiritual.app`; local development version `0.1.0`. Store identity has not been reserved or verified.
- Lessons and interface ship inside the package. No localhost server, external JavaScript, PWA worker or online first load is required for bundled content. Source websites still need internet.
- Safe-area insets use Capacitor's Android fallback and iOS CSS environment values. Toast positions also include the bottom safe inset. System-bar text follows the reader's paper/evening theme.
- Android Back first dismisses an open dialog, otherwise navigates backward; at the start it minimizes the app. It does not explicitly terminate unsaved in-memory work.
- The optional reading timer pauses on native inactivity and browser visibility changes. It never auto-resumes. Async listener disposal is tested for React cleanup races.
- Native feedback sharing opens the system share sheet with feedback-only JSON. The user chooses the destination. Reflections and practice history are not included, and no successful delivery is claimed.
- App-specific English/Hindi storage text preserves consent and shared-device cautions. Browser records do not automatically migrate into the installed app. Storage remains unencrypted by the app; unsaved drafts can be lost if the OS terminates it.
- Android backup and device-transfer rules exclude app data. The general privacy disclosure acknowledges that device backups may include data, particularly on the untested iOS target. No blanket backup guarantee is made.
